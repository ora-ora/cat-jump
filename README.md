# 🐱 小猫跳跳 Cat Jump

纯前端 HTML5 小游戏，仿 Doodle Jump 玩法。小猫会自动向上弹跳，玩家控制左右移动，踩着平台不断向上，掉出屏幕底部即结束。

无需构建、无外部依赖（不使用 CDN、图片或字体资源），所有画面均由 Canvas 绘制，音效由 WebAudio 实时合成。

## 文件说明

- `index.html` — 页面结构（开始界面 / 游戏 HUD / 结束界面）
- `style.css` — 样式与移动端适配（全屏、禁止滚动缩放等）
- `game.js` — 游戏逻辑、物理、渲染、输入与音效
- `README.md` — 本说明文件

## 如何运行

**方式一：直接打开**

双击 `index.html`，用浏览器（Chrome / Safari / Edge 等）直接打开即可游玩。

**方式二：本地静态服务器（推荐，体验更接近真机）**

在本目录下执行（任选一种）：

```bash
# Python 3
python3 -m http.server 8000

# Node.js（需先全局安装 serve）
npx serve .
```

然后在浏览器访问 `http://localhost:8000`，手机可通过同一局域网访问电脑的 IP 地址（如 `http://192.168.x.x:8000`）进行真机测试。

**方式三：静态托管**

可直接将这三个文件上传到任意静态托管服务（GitHub Pages、Vercel、Netlify、Nginx 等），无需任何构建步骤。

## 操作方式

- **手机端**：按住屏幕左半边 / 右半边控制小猫左右移动，也可以左右拖动手指
- **桌面端**：方向键 ← → 或 A / D 键
- 点击右上角喇叭图标可静音 / 取消静音（状态会保存）

## 玩法说明

- 小猫会自动弹跳，踩到平台会继续向上弹
- 平台分三种：普通（绿色）、移动（蓝色，会左右移动）、易碎（粉色，踩一次后碎裂消失）
- 偶尔会出现弹簧（大幅度超级跳）和小鱼干（增加分数）
- 随着高度上升难度逐渐提升，但平台间距始终保证可以跳到，不会出现无法到达的情况
- 左右移出屏幕边缘会从另一侧穿出（循环屏幕）
- 掉出屏幕底部即游戏结束，可查看本次得分与历史最高分（保存在本地）
